Vendored Dependency Archive

This folder holds the packaged Bitnami PostgreSQL archive that the
`shared-postgresql` wrapper chart depends on (aliased `bundled` in its
Chart.yaml). It is regenerated by `./hack/helm-dependency-update.sh` and
should not be edited by hand.

```mermaid
flowchart TD
  Bitnami[postgresql-14.3.3.tgz] --> Wrapper[shared-postgresql wrapper chart]
  Wrapper --> Umbrella[dlh-in-a-box umbrella chart]
```
