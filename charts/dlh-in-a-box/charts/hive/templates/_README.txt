# Hive Templates

This directory contains the Kubernetes resources generated by the local Hive
subchart.

## Template flow

```mermaid
flowchart LR
  Helpers[_helpers.tpl] --> Names[stable names]
  Catalogs[global.dataCatalogs] --> Config[configmap.yaml]
  Catalogs --> Metastore[metastore.yaml]
  InitConfig[init-config.yaml] --> Metastore
  PgSecret[postgres-secret.yaml] --> Metastore
  S3Secret[s3-secret.yaml] --> Metastore
  InitJob[init-schema-job.yaml] --> Postgres[(PostgreSQL)]
```

## File map

| File | Purpose |
| --- | --- |
| `_helpers.tpl` | Naming and catalog helper logic |
| `configmap.yaml` | Per-catalog Hive configuration ConfigMaps |
| `init-config.yaml` | Bootstrap configuration consumed during init |
| `init-schema-job.yaml` | Optional schema-init hook job |
| `metastore.yaml` | Per-catalog Service, Deployment, and optional Ingress resources |
| `postgres-secret.yaml` | PostgreSQL Secret creation when an existing Secret is not supplied |
| `s3-secret.yaml` | Storage credential Secret creation when an existing Secret is not supplied |

## Maintainer note

`metastore.yaml` is the center of gravity here. Changes to Hive startup,
mounts, or ingress behavior usually land there and should be tested with a real
overlay.
