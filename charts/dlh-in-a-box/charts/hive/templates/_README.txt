# Hive Templates

This directory contains all Kubernetes resources generated by the local Hive
subchart.

## Template flow

```mermaid
flowchart LR
  Helpers[_helpers.tpl] --> Names[stable resource names]
  Catalogs[global.dataCatalogs] --> Config[configmap.yaml]
  Catalogs --> Metastore[metastore.yaml]
  InitConfig[init-config.yaml] --> Metastore
  PostgresSecret[postgres-secret.yaml] --> Metastore
  S3Secret[s3-secret.yaml] --> Metastore
  InitJob[init-schema-job.yaml] --> Postgres[(PostgreSQL)]
```

## File map

| File | Purpose |
| --- | --- |
| `_helpers.tpl` | Naming and catalog sanitization helpers |
| `configmap.yaml` | Generates per-catalog `core-site.xml` and `metastore-site.xml` ConfigMaps |
| `init-config.yaml` | Provides PostgreSQL host and port to init logic |
| `init-schema-job.yaml` | Optional post-install or post-upgrade schema init hook job |
| `metastore.yaml` | Creates per-catalog Service, Deployment, and optional Ingress resources |
| `postgres-secret.yaml` | Creates a PostgreSQL credential secret unless an existing secret is supplied |
| `s3-secret.yaml` | Creates an S3 credential secret unless an existing secret is supplied |

## Maintainer note

`metastore.yaml` is the center of gravity here. It owns the init-container
bootstrap path, the running metastore container, and the optional ingress
surface, so changes there should be tested with at least one local deployment
overlay.
