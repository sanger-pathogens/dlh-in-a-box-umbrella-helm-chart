# Code of Conduct

This repository is maintained as a professional and respectful collaboration
space for people using, operating, and stewarding `dlh-in-a-box`.

## Our standards

We expect participants to:

- communicate respectfully and assume good intent
- focus feedback on the work rather than the person
- be constructive, specific, and professional in issues, reviews, and other discussions
- respect differing levels of experience and meet people where they are
- help keep technical discussions accurate, calm, and useful

Unacceptable behavior includes:

- harassment, discrimination, or personal attacks
- intimidation, trolling, or deliberately inflammatory behavior
- sharing private, sensitive, or confidential information without permission
- repeated bad-faith argument after a maintainer has set a boundary or closed a topic

## Scope

This Code of Conduct applies to repository discussions, issues, pull requests,
review comments, and other project-managed communication channels.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, do
not escalate it publicly.

Report it privately to the repository maintainers and code owners defined in
[.github/CODEOWNERS](.github/CODEOWNERS), or use an existing private
maintainer contact route within the Wellcome Sanger Institute, Parasites and
Microbes program, Data Engineering and Integration team.

If the report concerns a security issue, follow [SECURITY.md](SECURITY.md)
instead.

## Maintainer responsibilities

Maintainers may edit, hide, lock, or remove content that is inconsistent with
this Code of Conduct, and may limit participation where necessary to protect
the health of the project.
